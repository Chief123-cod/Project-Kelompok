# MID PROJECT WEB DESIGN — LUMORA E-COMMERCE

## Deskripsi
LUMORA adalah website e-commerce statis bertema fashion dan lifestyle. Project ini dibuat untuk memenuhi ketentuan Mid Project Web Design dengan HTML, CSS, dan Bootstrap.

## Halaman
1. `index.html` — Home
2. `about.html` — About
3. `products.html` — Products
4. `gallery.html` — Gallery
5. `contact.html` — Contact

## Ketentuan yang dipenuhi
- Minimal 4 halaman: **5 halaman**
- Navbar: tersedia di semua halaman
- Hero/Banner: tersedia pada Home dan page banner pada halaman lain
- Minimal 4 section Home: lebih dari 4 section
- Minimal 6 card/content item: 6 product card + content lain
- Minimal 6 gambar: tersedia pada Home, About, Products, Gallery
- Gallery: tersedia
- Form: tersedia pada Contact
- Footer: tersedia di semua halaman
- Minimal 4 komponen Bootstrap: Navbar, Card, Button, Badge, Form, Alert, Accordion, Pagination, Grid
- Custom CSS: `css/style.css`
- Responsive Design: Bootstrap Grid + media query CSS

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka folder project.
3. Buka `index.html` menggunakan browser.
4. Navigasi halaman menggunakan menu Navbar.

## Teknologi
- HTML5
- CSS3
- Bootstrap 5.3.3 melalui CDN

## Catatan
Website ini sengaja tidak menggunakan JavaScript untuk logic aplikasi. Beberapa markup Bootstrap seperti navbar collapse dan accordion menggunakan atribut Bootstrap, tetapi project tetap berfokus pada HTML, CSS, dan Bootstrap sebagai materi utama.

## Mengapa tidak memakai JavaScript?
Project ini berfokus pada HTML, CSS, dan Bootstrap sesuai instruksi. Navbar dibuat menggunakan layout flex Bootstrap sehingga tetap dapat digunakan pada layar kecil tanpa membutuhkan JavaScript. Form juga bersifat statis dan tidak mengirim data ke server.
